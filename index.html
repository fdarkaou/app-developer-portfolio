App developer portfolio report

See every iOS app one App Store developer ships: price, rating, monthly downloads and monthly revenue with the change since last month, paid-ad counts, and the studio's 90-day trend. Paste one developer response below. Nothing leaves your browser.

Where to get the JSON

The input is the developer response from PeekPanda, an iOS competitor catalogue that keeps dated evidence and nightly download and revenue estimates for each app. Use Apple's numeric developer id, the number after id in an App Store developer link:

curl https://api.peekpanda.com/v1/developers/ios/1000000000 \
  -H "Authorization: Bearer $PEEKPANDA_TOKEN" \
  -H 'x-genviral-tenancy: personal'

Over MCP this is the search_apps tool with action developer. You need a PeekPanda account and an API key; the get an app developer reference lists the fields and errors.

How to read it

  • Downloads and revenue are worldwide monthly App Store estimate ranges in USD, not numbers reported by Apple or the developer.
  • Totals add up only the scored apps. Apps under the floor and apps with no estimate are counted apart, never added in.
  • The trend line is the total mid estimate per day. A dot marks a day when the number of scored apps changed: a jump there means more apps were scored, not growth.
  • "unknown" means no estimate or ad count is stored for that app. It is unknown, not zero.
